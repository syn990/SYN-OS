# Default apps

Choose what opens your files and links from Preferences → Default Apps.
It's a live menu, like Audio and Display: every time you open it, it
shows what's installed right now and which app is in charge.

Things are grouped the way you think about them, not by file format:
Web browser, Folders, Archives, Text and code, Images, Audio, Video, PDF
and e-books, Torrents. Each one lists the apps that can open it, with
the current one marked [DEFAULT]. Click another and from then on that
kind of file opens there: from SYN-SHELL, from a download in the
browser, from anywhere.

Picking an app covers the whole kind, every format in it that the app
can open, under every name that format goes by. So choosing a music
player for Audio catches MP3, FLAC, WAV and the rest in one go, and a
text editor for Text and code catches scripts, source code, JSON and
Markdown as well as plain text.

## Reading the menu

- **Audio: VLC media player** is who opens that kind of file now.
- **, mixed** means some formats the same app could open have been
  given to a different one. Picking an app again tidies that up.
- **(which can't open these)** means the app in charge doesn't say it
  can handle that kind of file at all. Pick one from the list.

## Going back

SYN-OS ships its own choices for every user: Falkon for the web,
SYN-SHELL for folders and archives, FeatherPad for text, feh for images
and VLC for audio and video. Your picks sit on top of those, and **Reset
to SYN-OS default** under a kind drops yours so SYN-OS's apply again. It
only appears once you've changed something.

**Edit mimeapps.list** opens your own choices as a text file, if you'd
rather edit them by hand.
