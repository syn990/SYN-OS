# The SYN desktop as Void's binary packages, for SYN_OS_PACKAGES=xbps: what
# desktop/order compiles, by the same categories, installed by `build.zsh
# void` onto our LFS base and kernel. Only what SYN-OS uses is named; xbps
# brings each one's dependencies, and syn-lfs-base (syn-lfs-base.zsh) stops
# it bringing what the base already has. xbps/order is what still compiles.
#
# A profile is the set of categories it installs, as in desktop/order.
profile full    baseCore netAndServices shellAndCLI desktopStack fontsI18n appsMedia synOS
profile minimal baseCore netAndServices shellAndCLI desktopStack fontsI18n synOS
